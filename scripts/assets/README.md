# Documentation source images

Originals `pnpm gen:operations` derives the modifier samples in
`assets/operations/` from. They are only used to build the README table and are
not part of the published package.

They are all cats and dogs, picked so that each operation is demonstrated on an
image its effect is legible on: fine fur for the resampling operations, a wide
tonal range for the contrast ones, and so on (see `SOURCES` in
`scripts/operations.ts`).
